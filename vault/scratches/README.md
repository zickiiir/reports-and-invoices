# Scratches

Gitignored working directory for ephemeral output — everything here except this README is excluded
from version control.

Use this instead of the harness scratchpad, `/tmp`, or loose files in the repo root, for working
files that only matter for the current task: in-progress plans, intermediate scripts, temp dumps,
notes to self. Nothing here is meant to survive the task it was created for.

Output worth keeping — investigation findings, design notes, analysis someone should be able to
find later — belongs in the wiki vault instead.
